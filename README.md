# Bill Splitter

A small Expo app that splits a restaurant bill. Enter the bill amount, pick a tip
percentage, choose how many people are paying, and the app shows what each person owes.

## Run it

```bash
npm install
npx expo start
```

Scan the QR code with the Expo Go app on your phone.

## Tests

```bash
npm test
```

GitHub Actions runs the tests and bundles the app for Android on every push to `main`.
